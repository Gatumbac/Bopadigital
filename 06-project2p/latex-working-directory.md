# BOPADIGITAL LaTeX working directory

The canonical working directory for the current report is:

```text
BOPADIGITAL/
```

The only active LaTeX entry point is:

```text
BOPADIGITAL/mainETS_english_se2.tex
```

All image assets are kept locally in:

```text
BOPADIGITAL/appendices/images/
```

The Overleaf ZIP intentionally excludes those images. They can be uploaded
separately to the location expected by the LaTeX source. The ZIP also excludes
old reports, generated PDFs, auxiliary files, and the abandoned scaffold.
